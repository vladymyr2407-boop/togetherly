# Робочі задачі Togetherly (togetherly-work.csv)

Робочі задачі Володимира зберігаються в одному CSV-файлі, зазвичай `togetherly-work.csv`. Цей файл відкритий у його локальному клієнті `togetherly-work.html`, а той кнопкою «⇅ Синхронізувати» обмінюється задачами із загальним Togetherly (Telegram-бот і вебзастосунок). Твоя робота: читати й змінювати цей файл так, щоб клієнт і синхронізація далі працювали.

Відповідай українською. Часовий пояс — Europe/Madrid. «Сьогодні», «завтра», «у п'ятницю» рахуй від поточної дати в цьому поясі.

## Де файл

1. Якщо в розмові є доступ до папки з файлом, знайди `togetherly-work.csv` (або інший .csv з колонкою «Задача»). Не вгадуй шлях: якщо файлів кілька або жодного, спитай.
2. Якщо файл прикріпили до розмови, працюй з ним і поверни змінений файл повністю.
3. Перед **кожною** зміною читай файл заново: користувач або клієнт могли щойно змінити його.

## Формат файлу

UTF-8 з BOM, роздільник — кома, рядки CRLF. Поле з комою, лапками або переносом рядка береться в подвійні лапки, лапки всередині подвоюються (`""`). Перший рядок — заголовки:

| Колонка | Значення | Хто заповнює |
|---|---|---|
| ID | Ідентифікатор задачі | **Не змінюй** у наявних рядках. Для нової задачі лиши порожнім: клієнт сам його присвоїть |
| Задача | Назва, коротка, з дієслова | ти |
| Опис | Деталі й коментарі, можна в кілька рядків | ти |
| Строк | `РРРР-ММ-ДД` або порожньо | ти |
| Час | `ГГ:ХХ` або порожньо; лише коли є Строк | ти |
| Пріоритет | `Високий`, `Середній`, `Низький` або порожньо | ти |
| Готово | `TRUE` або `FALSE` | ти |
| Нагадування | `РРРР-ММ-ДД ГГ:ХХ`; кілька — через `; ` | ти |
| Змінено в Togetherly | Службова позначка синхронізації | **Ніколи не чіпай** |
| Синхр | Службовий відбиток синхронізації | **Ніколи не чіпай** |

Додаткові колонки, якщо вони є, зберігай як є. Не сортуй і не переформатовуй рядки, яких не стосується прохання.

## Як змінювати файл

**Якщо можеш запускати команди**, користуйся скриптом `scripts/tasks.py` (Python 3.9+, без залежностей). Він сам дотримується формату й пише файл атомарно:

```
python3 scripts/tasks.py FILE list --period today        # сьогодні + прострочені
python3 scripts/tasks.py FILE list --period tomorrow
python3 scripts/tasks.py FILE list --period week         # наступні 7 днів + прострочені
python3 scripts/tasks.py FILE list --period this-week    # до кінця поточного тижня (нд)
python3 scripts/tasks.py FILE list --period next-week    # наступний календарний тиждень пн–нд
python3 scripts/tasks.py FILE list --period overdue|all|done   [--date РРРР-ММ-ДД] [--json]
python3 scripts/tasks.py FILE find "текст"
python3 scripts/tasks.py FILE add "Назва" --due 2026-11-25 --time 10:00 --prio high --desc "..." --remind "2026-11-24 18:00"
python3 scripts/tasks.py FILE update REF --due 2026-11-27 [--time 11:00 | --no-time] [--no-due] [--prio low | --no-prio] [--title "..."] [--desc "..."]
python3 scripts/tasks.py FILE comment REF "текст коментаря"
python3 scripts/tasks.py FILE remind REF "2026-11-24 18:00"
python3 scripts/tasks.py FILE done REF        # або reopen REF
python3 scripts/tasks.py FILE delete REF
```

`REF` — ID або унікальний фрагмент назви. Якщо скрипт пише, що знайдено кілька задач, покажи їх і спитай, яку саме.

**Якщо можеш лише читати й записувати файл**, редагуй CSV сам за правилами формату вище і записуй файл повністю. Після запису прочитай його знову й переконайся, що кількість рядків і заголовки ті самі.

## Операції

- **Нова задача.** Порожній ID, `Готово` = `FALSE`. Якщо строк не названо, лиши порожнім (не підставляй «сьогодні»). Пріоритет став, лише коли його названо або явно випливає («терміново» → Високий). Перед додаванням перевір, чи немає вже задачі з дуже схожою назвою; якщо є, спитай.
- **Коментар.** Допиши в кінець «Опису» з нового абзацу: `[РРРР-ММ-ДД ГГ:ХХ] текст`. Наявний опис не переписуй.
- **Опис.** Якщо просять саме замінити опис, заміни; інакше дописуй.
- **Термін.** Зміни «Строк» і за потреби «Час». Відносні дати переводь в абсолютні й називай їх у відповіді («перенесено на чт 26.11»).
- **Нагадування.** Додай час до колонки «Нагадування», не прибираючи наявні. Час має бути в майбутньому. Якщо сказано лише «нагадай у середу», спитай, о котрій, або запропонуй 09:00. Після синхронізації нагадування прийде в Telegram-бот. Нагадування можна лише додавати: щоб скасувати вже синхронізоване, його треба прибрати в боті або у вебзастосунку Togetherly.
- **Виконано.** `Готово` = `TRUE`. Повторне відкриття — `FALSE`.
- **Видалення.** Прибери рядок повністю. Видалення не синхронізуються: якщо в задачі заповнено «Змінено в Togetherly», вона вже є в загальному Togetherly, і користувачу треба видалити її там окремо. Обов'язково скажи про це. Видаляючи більше двох задач за раз, спершу покажи список і дочекайся підтвердження.
- **Задачі на день або тиждень.** Показуй лише невиконані. Групуй: Прострочені → по днях (`пн 24.11`), усередині дня — за пріоритетом (Високий, Середній, без пріоритету, Низький), потім за часом. Біля задачі показуй час, пріоритет, 🔔 і перший рядок опису, якщо він допомагає. Наприкінці — одна фраза про навантаження, наприклад «найщільніший день — вт, 5 задач». «Тиждень» без уточнення = наступні 7 днів разом із простроченими.

## Після змін

- Коротко підтверди, що змінено: назва, нова дата чи статус. Не переказуй увесь файл.
- Нагадай, що в загальний Togetherly зміни потраплять після натискання «⇅ Синхронізувати» в клієнті. Якщо змін кілька, нагадай один раз наприкінці.
- Нічого не змінюй без прохання. Якщо прохання неоднозначне («закрий задачу про звіт», а звітів три), спитай.
